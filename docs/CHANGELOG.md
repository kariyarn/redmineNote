# 레드마인 노트 2.3.5 (소스 코드)

## 2.28.3
- **작업 표시줄 아이콘이 빈 문서 모양으로 보이던 것**: 앱 창에 붙이는 '다시 실행할 때 쓸 아이콘'(System.AppUserModel.RelaunchIconResource)이 exe 안의 아이콘(`exe,0`)을 가리켜서, 업데이트로 exe 가 바뀌거나 아이콘 캐시가 어긋나면 고정한 아이콘이 빈 문서 모양으로 깨졌다.
  - 아이콘을 데이터 폴더의 `app-icon.ico`(켤 때 앱 아이콘을 복사, 업데이트에도 자리가 그대로)로 가리킨다(`appwin.stable_icon`). 바뀐 표식은 이미 떠 있는 창에도 다시 붙인다.
  - 설치 파일이 만드는 시작 메뉴 · 바탕 화면 바로가기에 앱 창과 같은 앱 ID(`AppUserModelID`: `RedmineNotes2.App` / 베타 `RedmineNotes2.App.Beta`)를 붙였다 — 작업 표시줄이 설치할 때마다 새로 만드는 이 바로가기로 창을 묶고 아이콘을 찾는다.
  - 이미 깨진 고정 아이콘은 한 번 고정 해제 → 다시 고정하면 된다.

## 2.27.0
- **노트 옆 칸**: 노트 오른쪽에 `☑ 할 일`과 `📝 진행 기록`을 둡니다. 주제 사전 칸과 따로라서 사전을 닫아도 보이고, 노트를 떠나면 같이 사라집니다. 위의 단추로 각각 숨기고 보이며(둘 다 숨기면 얇은 띠만 남음), 노트와의 사이 손잡이를 끌어 너비를 나눕니다(더블클릭 = 기본, 옆 칸은 최대 40%).
- **진행 기록**은 노트 본문에서 빼고 옆 칸에 최신 순 타임라인으로 둡니다(같은 내용을 두 번 보이지 않음). 옆 칸에서 쓰고(`Ctrl+Enter`), ✎ · 🗑 로 고치고 지웁니다. 노트 위 이동 바에서도 `할 일` · `진행 기록`을 뺐습니다.
- **목록 아이콘 줄**: 오늘 · 이력에서 노트를 열면 왼쪽 목록이 작업 표시줄처럼 아이콘(구분 BC · DR + #번호, 아래 칸에 상태)으로 접혀 노트 폭을 지킵니다. 마우스를 올리면 제목, 누르면 그 노트로 이동합니다. `»` 로 펼치고 `« 아이콘으로 접기`로 다시 접습니다(기억함).
- 진행 기록 포스트잇 보드 팝업(2.23)과 주제 사전 칸의 할 일 탭(2.25)은 없앴습니다. 보드 자리용으로 추가했던 진행 기록 칸(x · y · w · h · z · color · pinned)은 DB 에 남지만 쓰지 않습니다.

## 2.26.0
- 레드마인 원문에 **형광펜(4색) · 밑줄 · 굵게 · 메모**를 덧입힐 수 있습니다. 원문에서 글자를 끌어서 고르면 도구 막대가 뜨고, 칠한 곳을 누르면 색 바꾸기 · 메모 고치기 · 지우기(되돌리기 가능)를 합니다. 레드마인 원문 자체는 바뀌지 않습니다.
- 표시는 고른 글자와 앞뒤 글자로 다시 찾아서, 원문이 조금 바뀌어도(문장 추가 · 띄어쓰기 변경) 따라갑니다. 찾지 못하면 지우지 않고 원문 아래 "위치를 잃은 표시"로 남깁니다. 코드 상자 안은 칠하지 않습니다.
- 원문 카드 머리에 표시 수와 `표시 숨기기` 단추가 있습니다. 메모 글은 검색에 걸립니다.

내 레드마인 일감을 PC에 노트로 모아 두고, 처리 내용·수정한 코드·이유를 기록하는 개인용 도구입니다.
레드마인에서 일감을 읽어 오고, 직접 버튼을 눌렀을 때만 **댓글 · 상태 · 담당자/개발담당자** 세 가지를 레드마인에 씁니다(삭제·그 밖의 수정은 못 합니다). 데이터는 각자 PC의 SQLite 파일에 저장됩니다.

## 2.1 에서 추가된 것 (최종 2.1.1)
- **댓글 바로 달기**: 노트 맨 아래 입력창, 그리고 어디서든 뜨는 `💬 댓글` 버튼/`C` 키 창. 두 곳은 같은 초안을 공유합니다. `Ctrl+Enter` 로 올립니다. 코드 상자(```)는 레드마인 Textile 로 바뀌어 올라갑니다.
- **한 번에 상태·담당자 지정**: `개발중` · `최종확인요청`(담당자=일감 작성자) · `완료` · `나로 지정`, 그리고 상태만 변경 / 이름으로 담당자·개발담당자 찾기. 처음 한 번만 안내·변경 확인 창이 나오고 '다시 보지 않기'를 누르면 더는 안 나옵니다(설정에서 다시 켤 수 있음).
- **안전장치**: 시험 모드는 해제됨 — **내 노트에 등록된(가져온) 일감이면** 어디서든 쓸 수 있고, 등록 안 된 일감은 서버가 거절합니다. 다시 제한하려면 `server.py` 의 `WRITE_ALLOW_IDS` 에 번호를 넣고 빌드하세요. 서버는 보낼 수 있는 항목을 제한합니다. 올리기 전에 일감을 다시 읽어 그 사이 바뀌었는지 확인하고, 같은 내용 중복 전송을 막고, 서버 오류 시 실제로 올라갔는지 다시 확인합니다. 모든 시도는 쓰기 기록(설정 창)에 남습니다. 
- **일감 안 이동 바**: 요건 · 진행 기록 · 처리 내용 · 코드/방법 · 이유 · 댓글 이력 · 연결된 일감 · 원문 (`Alt+1~8`). '처리 결과'는 **댓글 이력**으로 이름을 바꾸고, 댓글 이력·연결된 일감은 접고 펼 수 있습니다(기본 접힘).
- **코드 이력의 '내 관계'**: 내가 개발 / 관람 중 작성 / 남이 언급 / 참조(현재 역할 기준). 이름에 마우스를 올리면 횟수·마지막으로 쓴 날·일감 링크가 보이고, 코드 이력에서 관계로 걸러 볼 수 있습니다.
- **DR 도우미**(이력): `DR 이번 주`(DR · 개발담당자 · 최근 7일), `DR 현안`(DR · 담당자 · 기간 없음 · 대기/진행), `제목 복사`.

## 1.x 와 달라진 점

| | 1.x | 2.0 |
|---|---|---|
| 화면 구성 | 위쪽 탭 + 역할/상태/구분 필터 막대 | 왼쪽 메뉴 **오늘 · 이력 · 내 기록** (+ 더 보기: 요약 · 그래프 · 코드 이력 · 주제 사전) |
| 처음 열면 | 필터를 직접 맞춰야 함 | **필터 없이** 지금 할 일이 바로 보임 |
| 가져오기 | 내 일감 + 연결된 일감까지 자동 수집 | **내가 담당자·개발담당자·관람자인 것만**. 연결된 일감은 노트 안에서 한 건씩 눌러서 받음 |
| 실패 | 번호만 보임 | 사유별로 묶어 한국어로 설명, 다시 볼 수 있음 |
| 그래프 | 모든 노트 | 기본은 내 일감만 (완료·관람·참조는 토글) |

### 역할을 이렇게 나눠 봅니다
- **내 작업** = 담당자 + 개발담당자 둘 다 나인 것 → 오늘의 "지금 할 일" 맨 위
- **내 앞으로** = 담당자만 나인 것 → "지금 할 일"에 같이 표시
- **개발 담당** = 개발담당자만 나인 것 → 이력과 "참고"(현안은 접어서만)
- **관람** = 관람자만 → 이력에서 "관람 포함"을 켜야 보임
- **참조** = 연결돼서 따로 받은 것 → 기본으로 숨김 (지우지는 않음)

## 1. 그냥 쓰기만 하려면
`RedmineNotes2.exe` 하나만 받아서 실행하세요 (윈도우 10·11 64비트, 크롬 또는 엣지 필요).
처음 실행하면 "알 수 없는 게시자" 경고가 뜹니다 → **추가 정보 → 실행**.
첫 화면에서 본인의 레드마인 **API 키**(레드마인 → 내 계정 → API 접근 키 → 표시)를 붙여넣으면 시작되고, 과거 이력까지 볼 수 있게 **최근 1년**을 가져옵니다.
1.x 를 쓰던 PC 에서는 노트·설정을 **복사해서** 가져오므로 다시 입력할 필요가 없습니다 (1.x 데이터는 그대로 남습니다).

## 2.1.1 정리
- 노트 전체를 큰 블록으로 묶음, 댓글 입력창에서 코드 상자 바로 적용, 첨부파일 보기·내려받기, 일감 새로 읽기(`↻`, 노트를 열 때 자동), 요약의 현안 카드, `Ctrl+Q` 종료(확인 창).
- 상태 분류: `최종확인요청`·`완료` = 완료 / `접수`·`백로그`·To-Do = 대기 / 그 밖 = 진행 / `중단`·`보류` = 중단. 현안 = 대기 + 진행.
- 첨부파일 올리기, 코드 이력 '내 관계' 2차(수동 분류)는 다음 버전.

## 2.2.0 정리
- 노트: 처리 내용·수정한 코드/방법·수정 이유를 **정리 기록**(탭 3개) 한 칸으로 합침(저장 데이터 그대로), 연결된 일감은 큰 블록 밖 맨 아래, 이동 바는 맨 위에 고정(Alt+1~6).
- 댓글 표시를 한 함수(`remoteText`)로 통일: HTML(`<p>`)·Textile·일반 글 모두 태그 없이, 코드는 코드 상자로.
- **현안**(`isNow`) = 지금 담당자가 나 + 대기·진행, 기간 무관. 오늘·요약·DR 현안·이력 ‘현안만’이 같은 기준.
- **범위**(`inScope`): ‘관람·참조 포함’ 스위치 하나를 이력·용어 사전·그래프·요약이 함께 사용.
- 통일: 확인 창은 전부 앱 자체 창(`askC`), 복사 알림(`copyText`), 시각 표기(`dTime`), 접는 화살표(`chev`), 일감 줄(`nrow`).

## 2.3.0 — 메모(포스트잇)
- 왼쪽 메뉴 **메모**: 코르크보드 + 포스트잇. 하루가 보드 한 장이고 `Ctrl+N` 으로 오늘 보드에 새 포스트잇(크롬이 Ctrl+N 을 가져가면 메모 화면의 `N` 키·＋ 버튼).
- 레드마인·용어 사전·검색과 **완전 분리**된 별도 표(`sticky`)에 저장되고 백업에 포함된다. 검색은 메모 화면 안에서만.
- API: `GET /api/sticky?day=` · `/api/sticky/days` · `/api/sticky/search?q=` · `POST /api/sticky` · `DELETE /api/sticky/<id>`

## 2.3.1 — 메모 보강
- 보드가 포스트잇이 놓인 곳을 따라 **상하좌우로** 늘어남(음수 자리 허용). 새 포스트잇은 판 안 빈틈에 무작위, 꽉 차면 무작위 방향으로 넓혀 바깥에.
- `Ctrl+Enter` = 편집 종료·저장. 자동 배치(정렬·스프레드·랜덤)는 겹치지 않게, 📌 고정한 것은 제외.
- 삭제는 확인 창 대신 6초 **되돌리기**, `[ ]`/`[x]` 체크박스, 📅 달력, 내보내기(md/txt), 📌 고정(`pinned` 열 추가: 기존 DB 자동 변환).

## 2.3.2
- 메모 보드는 **크기 고정**(창 크기에 맞춤, 늘어나지 않음). 가득 차면 겹쳐 붙고 알림. 자동 배치(정렬·스프레드·랜덤)도 보드 안에서만.
- 새 포스트잇 단축키 `Ctrl+N` 을 window 캡처 단계에서 받음(편집기가 키를 가로채도 안 놓침) + `Alt+N` 보조. 편집 중 `Esc` / `Ctrl+Enter` = 저장하고 나가기.
- 앱 창이 열릴 때 **화면 가득(최대화)** (`--start-maximized` + 새 창 최대화). 사용자가 줄인 크기는 다시 건드리지 않음.

## 2.3.3 (A단계)
- **댓글·첨부 시각을 한국 시간으로** 표시 (레드마인 API 의 UTC 를 보여 줄 때만 변환: `lDay`/`lClock`/`dTime`). 날짜만 있는 값은 그대로.
- **노트 문서 스타일**: 굵은 구분선 + 큰 제목 + 읽기 좋은 폭. 설정 → 노트 모양에서 `문서 스타일` / `기존 스타일(카드)` 선택(`ui.noteStyle`, 기본 문서).
- **DR 제목 모아보기 필터**: 기간(7일·이번 달·직접) · 상태(레드마인 상태 이름) · 내 역할 · 내가 요청한 것만, 복사 시 `상태 포함` (`ui.drF` 에 저장).

- DB 열 `desc_raw`, `changes` 추가(자동 변환).

- 레드마인 전체 검색: **기간**(1개월·3개월·1년·전체, 기본 3개월, `ui.rmDays`)을 서버에 `days` 로 넘겨 `updated_on>=` 로 좁힘 → 빨라짐.

- **패치 노트**: 새 버전 첫 실행 때는 오늘 바뀐 것만 짧게(`PATCH_NOW`), 예전 1.x→2.x 안내는 설정 → 패치 노트 → 레거시(`PATCH_LEGACY`).

## 2.6.1
- **메모 보드**: 배경을 도트(기본) · 격자 · 코르크로 바꿀 수 있음(`ui.memoBoard`, 메모 화면 위쪽 `도트/격자/코르크`). 보드·포스트잇 디자인 정리(채도 낮은 파스텔, 얇은 테이프, 부드러운 그림자). 도트·격자는 테마 색을 따라감.
- **레드마인 검색**: 프로젝트 칩·기간·완료 빼기를 바꿔도 **자동 검색하지 않음**. 바뀌면 `검색` 버튼이 강조되고 안내가 뜨며, 버튼 또는 검색창 Enter 로 검색(검색어를 직접 입력할 때의 자동 검색은 그대로).
- **팀 태그 필터**: 결과의 제목 앞 `[제휴본부]` 같은 태그를 칩으로 모아 거름(여러 개 선택 = 하나라도, `태그 없음` 포함). 이미 받은 결과 안에서만 거름(서버가 제목 앞부분 조건을 지원하지 않음).

## 2.6.2
- **사진**: 첨부로만 올린 사진(글에 `!파일.png!`로 끼우지 않은 것)도 첨부 목록의 다운로드 줄이 아니라 **그 댓글 아래 / 본문(원문) 아래에 바로** 표시(`fillAttPlaces`, 첨부 응답에 `journal_id` 추가). 글에 이미 끼워진 사진은 중복 표시 안 함. 첨부 카드의 사진 줄은 썸네일 + `⬇ 저장`, 노트 위 사진 줄에도 포함.
- **사진 뷰어**(`#lbox`): 휠·＋－·두 손가락 확대/축소(10%~1000%), 끌어서 이동, 사진 클릭=맞춤↔확대 전환, `맞춤`·`100%`·`저장` 버튼, ←→ 앞뒤 사진, 키보드 `+ - 0 1`, 빈 곳 클릭/Esc 로 닫기.

## 2.6.3
- **노트의 요건 구역을 없애고 그 자리에 `레드마인 원문`**(기본 펼침, 사진·코드 상자 포함)을 둠. 맨 아래에 있던 원문 블록은 제거. 요건 편집 기능 삭제.
- 이동 바: `원문 · 진행 기록 · 정리 기록 · 댓글 이력 · 연결된 일감`, 단축키 `Alt+1~5`.
- 예전에 직접 고친 요건(`requirement` 가 본문과 다른 노트)은 **지우지 않고** `예전에 내가 고친 요건`(읽기 전용, 접힘) 카드로 보존. DB 열 `requirement` 와 코드 이력의 이름 추출은 그대로.
- `POST /api/note` 는 `requirement` 없이도 저장(보내면 예전처럼 반영). 편집 감지 기준은 `#rq` → `#ac`.

## 2.6.4
- **오늘 › 지금 할 일 정렬**: `기본`(내 작업 먼저 · 오래 둔 것부터) · `최신순`(레드마인 수정일) · `등록순`(일감 번호) · `내 순서`(`ui.todaySort`, `ui.todayOrder`). 줄을 **끌어서 놓으면** 자동으로 `내 순서`가 되고 이 PC에 저장(레드마인에 쓰지 않음). 고정/일반 경계는 넘지 못함. 새 일감은 내 순서의 맨 아래.
- **고정(★)**: 모든 노트 목록의 줄 왼쪽에 ☆/★ 버튼(노트 상단 즐겨찾기와 같은 기능, `/api/star`). 고정한 것은 오늘의 지금 할 일 맨 위에 옴.

## 2.6.5
- **구역별 정렬**: 오늘 화면의 `최근 바뀐 것` · `참고(내가 개발 담당)` · `지켜보는 중` 에도 구역마다 따로 `최신순`(기본) / `등록순` 선택(`ui.secSort`). ★ 고정은 각 구역 맨 위. `지금 할 일` 은 기존대로 `기본/최신순/등록순/내 순서`(끌어서 바꾸기). `최근 바뀐 것` 은 최근 3일 중 가장 최근 6건을 고른 뒤 정렬.

## 2.7.0
- **메모 노출 기간**: `sticky.until`(종료일, 빈 값 = 그 날 하루). `GET /api/sticky?day=` 는 그 날 만든 것 + `시작일 ≤ 그 날 ≤ 종료일` 인 것을 돌려줌. 같은 포스트잇 하나라서 한 날에서 고치면 모든 날에 반영. 종료일이 시작일 이하면 하루짜리로 정리, 형식 오류는 400. `메모가 있는 날` 칩·달력의 숫자는 시작일에만 셈. 새 포스트잇 옆 `📅 기간 정해서`, 포스트잇 머리줄 `📅`, 기간이 있으면 `MM-DD~MM-DD` 표시.
- **보드 색**(`ui.memoBoardColor`): 메모 도구줄 `🎨 색상` 에서 팔레트(화이트·크림·민트·하늘·라벤더·핑크·차콜·코르크 갈색) · `직접 고르기` · `테마 따라가기`. 점·격자·안내 글자 색은 바탕 밝기에 맞춰 자동.

## 2.7.1
- **겹침 수정**: 포스트잇의 겹침 순서(고정은 100000+)가 대화창·팝업보다 위로 올라오던 문제 → `.cork{isolation:isolate}` 로 보드 안에 가두고 `.memo-h` 를 위로. 기간 정하기 창·색상 창 모두 포스트잇 위에 뜸.
- **색상 창이 바로 꺼지던 문제**: 색을 누르면 창 안을 다시 그려 눌린 버튼이 사라지고, 바깥 클릭 검사가 오판하던 것 → 이벤트 경로(`composedPath`)로 판단.
- **그래프 목록**: 한 번 클릭 = 그 노드 강조 고정(다시 클릭 = 해제), 더블클릭 = 노트 열기. 고정된 줄은 목록에서도 표시(`.gsel`).
- **오늘 배포요청 알림**: 오늘 날짜 배포요청 일감이 있으면 메뉴 `배포요청` 옆(접힌 `더 보기`에도) 🚀. 누르면 오늘 배포요청 열기. 설정 → 배포요청에서 `끔 / 켬(켤 때·창으로 돌아올 때 확인) / 자동(10분마다 확인, 새로 올라오면 알림, 기본)` (`ui.depAlert`). 일감 상태값은 보지 않음, 읽기만 함.

## 2.7.2
- **메모 📌 고정 모아보기**: 메모 도구줄 `📌 고정 모아보기 N` 을 누르면 고정(📌)한 포스트잇을 **날짜와 상관없이** 최근 날짜 순으로 카드로 모아 봄(체크 줄·코드 상자·기간 표시 포함). 카드에서 `이 날 보드로` 이동, `고정 해제`(포스트잇은 남음). `GET /api/sticky/pinned`.

## 2.7.3
- **포스트잇 머리줄이 바깥으로 튀던 문제**: 기간 표시 + 색 점 6개 + 버튼이 좁은 포스트잇 폭보다 길어 넘치던 것 → 머리줄 줄바꿈 허용, 색 점은 마우스를 올리면 아래로 뜨는 작은 팔레트(자리를 차지하지 않음), 버튼은 작게, 기간 표시는 넘치면 말줄임. 폭 140~320px 에서 모든 요소가 포스트잇 안에 있음을 측정으로 확인.

## 2.7.4
- **배포요청 로켓**: 오늘 배포요청의 상태가 `완료`면 🚀 대신 **착륙한 로켓**(초록 그림). 완료 시각 + 30분이 지났는데도 완료 이후에 달린 댓글이 있으면 다시 🚀. (완료 직후 30분 안의 마무리 댓글은 그대로 착륙.) 자동 모드에서는 바뀔 때 알림. `GET /api/rm/deploy/state?id=` (완료 시각·완료 뒤 댓글 수, 읽기 전용, 5초 캐시).

## 2.7.5
- **댓글 빈 줄**: 레드마인은 댓글을 HTML 로 보여 줘서 엔터만으로는 줄이 안 바뀐다. 예전에는 한 번 친 엔터만 `<br />` 로 바꿔서 **빈 줄(엔터 2번 이상)이 사라지고** 윗줄·아랫줄이 한 줄로 붙었다 → 엔터 친 횟수만큼 `<br />` (`_soft_breaks`). 코드 상자·목록·표는 그대로.
- **로켓 판단을 '댓글 흐름'으로** (`deploy_state`): 실제 배포요청 이력 16건을 확인한 결과 `상태 완료`는 요청이 하나도 없는 날(구분선만 있는 날)에도 찍히고, 완료 뒤에도 요청이 계속 오므로 상태로는 알 수 없음. 댓글을 `R`(`요청 사유` 양식) / `C`(구분선: `=====`·`절취선`, 또는 상태를 완료로 바꾼 기록) 로 나눠 순서대로 훑어 → 마지막 구분선 뒤에 요청이 남으면 **pending(🚀 대기 N건)**, 요청이 모두 구분선 앞이면 **landed(착륙)**, 요청이 한 건도 없으면 **idle(흐린 🚀)**. 완료 뒤에 요청이 오면 즉시 🚀 (이전의 '30분 뒤' 규칙은 폐기: 실제 이력에 잡담 댓글이 없고, 요청이 구분선 17분 뒤에도 오기 때문).
- **일감 열기**: 요약·그래프·코드 이력·배포요청·트러블슈팅·내 기록·메모에서 일감을 열어도 메뉴가 `이력`으로 바뀌지 않고 그 자리에 열림. 위쪽 `← 돌아가기 · ○○` 버튼(또는 `Alt+←`)으로 돌아옴 (`peeking()`, `closePeek()`). 오늘·이력은 그대로.

## 2.7.6
- **메모 상단 바**: 한쪽에 몰려 있던 메뉴를 두 줄로 묶음(위: 날짜 이동·달력·제목·검색 / 아래: `배치`·`보드`+🎨 색상·📌 고정 모아보기 … 내보내기·기간 정해서·새 포스트잇). 검색칸을 넓혀 `메모 검색 (전체 날짜)` 글자가 잘리지 않게 함.

- **빈 보드 더블클릭 = 그 자리에 새 포스트잇**(`newSticky({at})`, 보드 안으로 보정). 포스트잇·팝업 위의 더블클릭은 무시.

- **제목이 팀 태그로 잡히던 문제**: `[운영서버 배포요청 / 2026-10-07]` 처럼 제목 **전체**가 `[ ]` 이면 팀 태그가 아니라 그냥 제목으로 표시(`title()`, 그래프 라벨 `shortTitle`, 검색의 팀 태그 칩 `tagOf` 모두 `[ ]` 뒤에 글자가 있을 때만 태그로 인정).

## 2.10.3 — 지켜보는 중 정리
- **오늘 화면 › 지켜보는 중**: 줄에 마우스를 올리면 `✕ 숨기기`. 숨긴 일감은 이 구역에서만 빠지고(이력·검색·노트는 그대로) 가져오기를 다시 해도 유지된다. 숨길 때의 레드마인 수정일을 같이 저장해서, **그 뒤 일감에 새 활동이 생기면(수정일이 달라지면) 저절로 다시 나타난다.** 5초 되돌리기 토스트 + 구역 아래 `숨긴 N개 보기`에서 `↩ 되돌리기`.
- **자동 정리**: 관람 일감이 **N일(기본 14) 동안 변화가 없으면** 이 구역에서 자동으로 빠지고 `숨긴 N개`에 모인다. ☆ 고정한 것은 제외(고정하면 다시 보임). 설정 → 오래 대기 아래 `지켜보는 중 [N]일`(0 = 끔).
- 저장: 설정값 `watch_hidden`(JSON: 일감번호 → 숨길 때의 수정일), `watch_auto_days`.

## 2.12.0 — 기간 알림: 알림 받을 날 고르기
- 기간 메모의 🔔 설정 창에 **날짜별 체크박스**(기간이 2일 이상, 62일 이하). 기본 = 평일 전부(주말 · 공휴일 제외), `평일만 / 모두 / 해제` 단추. 체크한 날에만 알림이 오고, **직접 체크한 날은 주말 · 공휴일이어도 울린다.** 선택이 기본(평일 전부)과 같으면 따로 저장하지 않는다.
- 저장: `sticky.alarm_dates`(JSON 날짜 목록, 빈 값 = 기본). 기간을 바꾸면 기간 밖 날짜는 자동으로 빠지고, 메모 글·위치만 고치는 저장은 건드리지 않는다. 날짜를 고르면 알림을 새로 건 것으로 보고(소급 안 함) 예전 `확인함` 기록을 지운다. 하루짜리 메모에는 쓰지 않는다.
- 표시: 메모 머리줄 배지 `🔔09:30 ·2일`, 달력의 주황 점은 고른 날에만. 달력으로 끌어서 기간이 늘어나면 날짜를 고른 알림에는 놓은 날도 포함.

## 2.12.1
- **달력으로 끌어 놓을 때 기간이 있으면 알림 받을 날을 고른다**: 놓은 날 때문에 메모가 기간(시작일~종료일)이 되면(원래 기간 메모이거나, 다른 날로 놓아 기간이 늘어난 경우) 🔔 설정 창이 날짜 체크 목록과 함께 열린다. 놓은 날은 미리 체크, 기본은 평일 + 놓은 날(이미 날짜를 고른 알림이면 그 선택 + 놓은 날). 취소하면 아무것도 바뀌지 않는다. 하루짜리 메모는 이전처럼 시각만 묻고(이미 시각이 있으면 바로 건다), 62일을 넘는 기간은 날짜 선택 없이 평일 전체.

## 2.12.2
- **진행 기록 Ctrl+Enter**: 진행 기록을 **수정하는 중**이면 그 기록을 저장, **새로 쓰는 중**(내용이 있을 때)이면 추가. 코드 상자 안에서 눌러도 동작(원래 Ctrl+Enter 는 상자에서 빠져나오기였는데, 진행 기록 칸에서는 저장이 먼저). `window` 캡처 단계에서 처리, 한글 조합 중에는 무시. 저장 단추에 `Ctrl+Enter 또는 Ctrl+S` 안내.

- **언어 자동 추정 + 직접 선택**: 내용의 특징으로 점수를 매겨 추정(애매하면 일반 글), ``` 뒤에 적은 이름이 있으면 그것이 우선. 코드 상자 머리줄의 언어 선택으로 바꾸면 글에 ```` ```sql ```` 처럼 남는다. 읽기 화면 코드 상자 위에 언어 이름표.
- **✨ 정리**: SQL(절마다 줄바꿈 · 키워드 대문자 · 항목 한 줄씩 · AND/OR 들여쓰기 · 서브쿼리), JS/Java/CSS(`{ } ;` 에서 줄 나눔 + 괄호 깊이대로 들여쓰기), JSON, HTML/XML, **MyBatis XML**(태그는 줄 나누고 안쪽 SQL 은 SQL 규칙). **정리 전/후 미리보기**에서 직접 고친 뒤 적용, 취소하면 원본, 적용 뒤 토스트로 되돌리기. 자동으로 바꾸지는 않는다.
- **이름표(자리표시자)**: `:이름`(SQL) · `#{이름}` · `${이름}` 을 찾아 값을 입력받아 복사(SQL 은 문자열 따옴표 자동/그대로/'문자열' 선택, 미리보기). **📌 고정값**: 이름이 같은 이름표에 자동으로 채움(범위: 모든 곳 / 이 항목만), **전부 고정이면 창 없이 바로 복사**(토스트의 `값 바꾸기`로 변경), `📌 고정값` 에서 관리. 마지막 입력값은 기억해서 미리 채움.
- **코드/쿼리 보관함**(이름 변경): 언어 · **코드 위치**(클래스/파일 이름 여러 개, 코드에서 `class X` · MyBatis namespace · 파일 이름을 짐작해 채움, 눌러서 복사) · 연관 레드마인 · 태그 · 고정 · 사용 횟수. **모든 코드 상자**에 `📚 코드 보관함` 단추. 목록 필터는 DB 종류 → **언어**. 편집 칸은 노트와 같은 코드 상자(색칠 · 언어 선택 · 정리).
  - **버전 메모**: 제목 · 용도 · 언어 · 코드를 고칠 때 이전 내용을 항목마다 최근 10개 보관(`query_versions`), `🕘 이전 버전` 에서 보고 되돌림(되돌리기 전 내용도 남음). 정리 후 저장도 같다.
  - **내보내기/가져오기(JSON)**: 전체 / 지금 목록 / 이 항목만. 가져올 때 같은 코드(공백·대소문자 무시)는 건너뜀.
  - **노트 · 코드 이력 연결**: 노트의 `📚 관련 코드/쿼리` 는 **제목만** 보이고 누르면 코드가 팝업(색칠 · 복사 · 보관함에서 열기). 코드 이력에도 이름이 나오는 코드/쿼리가 `관련 코드/쿼리` 로 보임(트러블슈팅처럼 일감 건수에는 안 섞임).
- 저장: `queries.lang` · `queries.code_locs`(JSON) 추가, 표 `query_versions`. API: `GET /api/queries/versions?id=` · `POST /api/queries/restore` · `POST /api/queries/import`.
- 읽기 화면 코드 상자의 단추(복사 · 코드 보관함)는 첫 줄 코드와 겹치지 않게 윗줄 테두리 위로 올림.

## 2.15.0 — 자동 가져오기
- **자동 가져오기**(설정 → 자동 가져오기): 정한 간격(분, 최소 5분, 기본 끔)마다 **서버가 스스로** 레드마인에서 바뀐 일감을 가져온다. 창을 최소화하거나 닫아 트레이에만 있어도 돌고, **영업일(토 · 일 · 공휴일 제외) 08:30 ~ 18:30**(통상 업무 시간 ± 30분)에만 가져온다. 기간은 `최근 N일`(1 = 오늘만, 최대 · 기본 7일). 마지막 가져오기(직접 · 자동 · 처음 열 때 확인) 시각부터 간격을 재고, 한 번도 가져온 적이 없으면 하지 않는다(처음은 직접 최근 1년). 실패하면 간격마다 한 번만 다시 시도.
  - **공휴일**: 공공데이터포털 `한국천문연구원_특일 정보`의 공휴일 정보 조회(`getRestDeInfo`)로 **매주 첫 영업일에 그 주(월 ~ 일) 공휴일만** 받아 둔다(자동 가져오기가 켜져 있을 때만. 월요일이 공휴일이면 화요일, 앱이 꺼져 있었으면 그 주에 처음 켜진 영업일). 받지 못하면 1시간 뒤 다시. 받은 공휴일 + 내장 공휴일 표 + 설정의 추가 휴일로 쉬는 날을 판단. **인증키는 코드에 고정**(`holiday_api.SERVICE_KEY`, 사용자 입력 없음, 화면 · 응답에 안 나옴). 설정에 이번 주 공휴일 표시 · `이번 주 다시 받기`. `rnotes/holiday_api.py`, `POST /api/holiday/fetch`, settings `holiday_api`(받은 주별 공휴일).
  - **새 일감 알림**(기본 켬, `auto_sync_notify`): 자동 가져오기로 새 일감이 들어오면 창이 보일 때는 **알림 창**(`🆕 새 레드마인 일감 N건`, 누르면 노트 열기), 창이 안 보일 때(최소화 · 트레이)는 서버가 **윈도우 알림**(트레이 말풍선, 윈도우 10 에서는 오른쪽 아래 알림 · 알림 센터)으로 알린다(메모 알림과 같은 '보인다' 기준). **알림을 누르면 창이 열린다**(열려 있으면 앞으로, 트레이 아이콘을 누른 것과 같음 — 메모 알림 말풍선도 같다). 최소화했던 창으로 돌아오면 알림 창도 뜬다. 설정 → 자동 가져오기의 `새 일감이 들어오면 알림` 으로 끄고 켠다(끄면 알림 없이 목록에만 반영). 트레이는 exe 로 실행할 때만 있으므로 소스 실행(`python main.py`)에서는 말풍선 없이 창으로 돌아왔을 때 알림 창만 뜬다.
  - 켜 두면 창을 닫아도 서버가 스스로 꺼지지 않는다(`idle_watchdog`, 알림이 남아 있을 때와 같음). 끄려면 트레이 → 서버 닫기 또는 Ctrl+Q.
  - 화면은 30초마다(창으로 돌아오면 바로) `GET /api/autosync?since=` 로 결과를 받아, 바뀐 일감이 있으면 다시 읽어 그리고 `자동 가져오기: 신규 N · 변경 M건` 을 띄운다. 글 쓰는 중 · 편집 화면 · 대화 상자 · 창이 가려진 동안에는 **다시 그리기만** 미룬다(쓰던 글이 날아가지 않게). `가져오기` 아래 상태 줄에 `자동 N분`(마우스를 올리면 기간 · 시간대 · 다음 예정 시각).
  - 저장: 설정값 `auto_sync_min` · `auto_sync_days` · `auto_sync_notify`. 서버 `rnotes/autosync.py`(스케줄러 `autosync_loop`, 30초마다 확인), 가져오기는 한 번에 하나씩(`redmine.SYNC_LOCK`: 직접 가져오기와 겹치지 않게). 시험 `tests/test_autosync.py`.

## 2.16.0 — 깃허브 백업 · 왼쪽 메뉴 정돈
- **깃허브 백업**(설정 → 깃허브 백업, #4): `notes.db` 스냅샷을 내 **비공개** 깃허브 저장소에 올린다(등록한 폰트는 올리지 않는다). 동기화가 아니라 백업이라, **올리기만 자동**이고 **내려받기(복원)는 백업 시점 목록에서 직접** 고른다(복원 직전 상태는 로컬 `before-restore` 백업). 그 시점을 zip 파일로 받을 수도 있다.
  - 올리는 때: `자동 올리기` 를 켜면 ① **앱 창을 닫을 때**(창이 닫히는 순간 + 프로그램 종료 때)는 늘 올리고 ② 켜져 있는 동안 **N시간마다**(0 ~ 24, 기본 3, 0 = 닫을 때만) 올린다. 마지막으로 올린(또는 올려 본) 때부터 재서, **꺼져 있던 사이 N시간이 지났으면 켤 때 한 번만** 올린다(밀린 횟수만큼 올리지 않음). 올리는 중에 들어온 요청(닫기 · 시간 · 다시 시도)은 쌓지 않고 **마지막 것 하나만** 남겼다가 한 번 올린다. 바뀐 게 없으면(파일의 깃 blob sha 비교) 올리지 않는다. 네트워크 · 서버 오류면 15분마다 다시 해 보고, 실패는 트레이 말풍선으로 한 번 알린다. 백업 때문에 서버를 켜 두지는 않는다.
  - **PC 한 대 기준**: 저장소 최신 기록이 이 PC가 마지막으로 올린(또는 복원한) 기록이 아니면 덮어쓰지 않고 멈춘다. `그래도 이어서 올리기` 를 누르면 그 위에 이어서 올린다(기존 기록은 지우지 않는다). 처음 연결한 저장소에 이미 노트 백업이 있어도 확인을 받는다.
  - 공개(Public) 저장소 · 쓰기 권한 없음 · 100MB 넘는 파일은 막는다. 토큰(fine-grained, Contents 읽기/쓰기)은 `HOME_DIR/gitbackup.json` 에 DPAPI 로 암호화해 두고 화면 · 응답 · 백업에 넣지 않는다. 설정(저장소 · 올리는 때 · 마지막 결과)도 이 PC 의 그 파일에만 있어서 노트를 복원해도 바뀌지 않는다.
  - 깃허브 Git Data API 로 한 번에 커밋(blob → tree → commit → ref 빨리 감기만). 빈 저장소면 README 로 첫 커밋, 기본 브랜치가 아닌 백업 브랜치는 기본 브랜치에서 만든다. 커밋에는 `backup-info.json`(버전 · 시각 · PC · 노트 수)도 같이 올린다.
  - 서버 `rnotes/gitbackup.py`(30초마다 확인하는 `loop`, 종료 때 `on_shutdown`), API `GET /api/gitbackup` · `/history` · `/download?sha=`, `POST /api/gitbackup/config` · `/check` · `/upload` · `/restore` · `/disconnect`. 시험 `tests/test_gitbackup.py`(가짜 깃허브 `tests/fake_github.py`).
- **설정 창 정리**: 한 화면에 길게 이어지던 설정을 **왼쪽 탭**(`일반 · 가져오기 · 기준 · 화면 · 글꼴 · 레드마인 쓰기 · 백업`)으로 나누고 오른쪽 내용만 스크롤한다(좁은 창에서는 탭이 위로). 마지막에 본 탭을 기억한다. 항목은 `이름 | 조절` 한 줄 모양으로 맞추고, 긴 설명은 `자세히` 로 접었다. **백업 파일 · 최근 쓰기 기록 · 깃허브 백업 시점**은 개수만 보이게 접어 두고(펼친 상태 기억), 펼쳐도 높이를 넘으면 그 안에서 스크롤한다. 화면 디자인 · 노트 모양 · 메뉴 줄 간격 · 확대/축소는 `화면 구성` 하나로 모았다.
- **왼쪽 메뉴 정돈**: 새 디자인의 메뉴 묶음(일감 · 내 도구 · 보관함 · 분석)을 제목으로 접고 편다(저장, 지금 보는 화면이 든 묶음은 펼쳐 둠, 접힌 묶음은 제목 옆에 숫자 · 🔔 · 🚀). 설정 → 화면 디자인에 **메뉴 줄 간격(보통 / 촘촘)**. 가져오기 단추 옆 ▸ 로 마지막 가져오기 · 기간을 접는다('확인 필요'는 접어도 보임). 메뉴가 길면 메뉴 목록만 스크롤하고 가져오기 · 달력 · 설정은 아래에 남는다.

  - 예전에 받아 ID 가 0 인 일감: 가져오기(직접 · 자동)의 목록에 들면 수정 시각이 같아도 상세를 한 번 다시 받아 채운다(결과에서 '변경'으로 세지 않아 자동 가져오기 알림 · 다시 그리기도 생기지 않음). 목록에 들지 않는 일감(배포요청 · 연관 등)은 노트를 열 때 다시 읽으며 채워지고, 그 전까지 화면은 이름으로 판별한다.
  - 배포요청 화면의 `지난 30일 가져오기`(`/api/fetch`)도 이미 있는 일감의 ID 가 0 이면 다시 받아 채운다(구분 유지). 다시 받기에 실패해도 이미 있는 일감이라 실패 · 건너뜀으로 남기지 않고 그대로 연다.

  - 배포요청 일감 판별: 화면에서 연 것뿐 아니라 **배포요청 프로젝트(`request-2021`) · 제목('배포요청 / 날짜')**이면 어느 경로(일반 · 자동 가져오기 등)로 받든 저장할 때 '배포요청' 구분을 붙인다(`redmine.is_deploy_issue`, 프로젝트 번호는 `/projects/request-2021.json` 으로 한 번 알아 두고 1시간 캐시, 못 읽으면 5분 뒤 다시). 예전에 받은 일감은 작성자 ID 를 채우려고 다시 받을 때 같이 고쳐진다. 자동 가져오기의 새 일감 알림(창 · 트레이) · 개수에서도 배포요청 일감은 뺀다.

## 2.17.0 — 돌아온 최종확인요청 · 안 본 일감 강조
- **돌아온 최종확인요청을 지금 할 일에**(#12): 상태가 `최종확인요청`이어도 담당자가 나(내 작업 · 내 앞으로)면 오늘의 `지금 할 일`에 넣는다. `최종확인요청` 버튼은 담당자를 요청자에게 넘기므로, 담당자가 나라는 건 요청자가 다시 돌려보냈다는 뜻이다. 상태 묶음(`stOf`)은 그대로 완료라서 이력 · 요약 · 통계 숫자는 바뀌지 않는다. `web/js/layout.js` `isNow`.
- **안 본 일감 강조**: 새로 왔거나 레드마인에서 바뀌었는데 아직 열어 보지 않은 일감은 목록 줄(`.nrow.unseen`) 배경을 칠한다(테마의 `--warn` 색을 옅게, 선택된 줄 강조가 우선). 일감별로 마지막으로 열어 본 수정일을 설정값 `rm_seen`(`{_base, ids:{번호: updated_on}}`)에 저장하고, 기록이 없으면 `_base`(처음 켰을 때 · 첫 가져오기 직후의 가장 최근 수정일)보다 나중에 바뀐 것만 안 본 것으로 친다. 노트를 직접 열면(열어 둔 채 새로 읽기 · 자동 가져오기로 바뀌어도) 본 것으로 바뀌고, 오늘 화면이 자동으로 오른쪽에 연 노트는 열어 본 것으로 치지 않는다. 이 앱에서 레드마인에 올린 뒤에도 본 것으로 기록한다. 목록에 없는 일감 기록은 저장할 때 지운다.

## 2.18.0 — 명령어 변수 · 버튼 접기
- **명령어 버튼 접기**: 댓글 입력창 아래 명령어가 6개(`CMD_BTN_MAX`) 이하면 모두 버튼, 넘으면 선택칸(`그 밖의 명령어… (N)`) 하나로 접는다. 명령어 편집의 **버튼으로 꺼내 두기**(`commands.pinned`)를 켠 것은 접혀도 버튼으로 남는다. 누르면 지금처럼 입력란을 그 문구로 바꾼다.
- **명령어 변수**(보관함 → 명령어 → `변수` 탭): 문구 안의 `#{이름}` · `#{이름(인수, …)}` 을 바꿔 넣는다. `\#{…}` 는 바꾸지 않고 `#{…}` 로 남긴다.
  - **상수**: 값을 그대로. **함수**: 사용자가 쓴 JavaScript 함수 본문(`ctx`, `args`, `await` 가능)을 실행해 `return` 한 값을 넣는다. `ctx` = `now` · `fmt(날짜, "YYYY-MM-DD HH:mm")` · `addDays(n, 날짜)` · `nextWeekday(0~6, 날짜)` · `issue`(지금 일감 id · subject · project · tracker · status · author · assignee · url, 일감 밖에서는 null) · `me` · `vars`(상수들).
  - 함수는 함수마다 따로 띄운 Worker 에서 3초(`CMD_FUNC_MS`) 안에 실행한다(화면 · 저장 데이터 · 레드마인에 손대지 못하고, 멈추면 끊는다). 못 바꾼 자리(없는 변수 · 오류 · 시간 초과)는 그대로 남기고 이유를 알린다.
  - 편집 화면: 이름 · 유형(상수 / 함수) · 값(함수는 코드 글꼴) · 설명, 인수를 넣어 **실행해 보기**. 명령어 편집에는 변수 넣기 버튼과 **미리 보기**, 명령어 보기에는 미리 보기(지금 시각 · 마지막으로 연 일감 기준).
  - 예전 날짜 자동 입력 `#{nextTue}` · `#{nextThu}` 와 `#{today}` 는 처음 한 번 기본 함수 변수로 넣는다(지우거나 고쳐도 다시 넣지 않음, settings `cmd_vars_seeded`).
  - 저장: 테이블 `cmd_vars`(이름은 대소문자 무시하고 중복 불가 · 글자/_ 로 시작 · 40자), API `GET/POST /api/cmdvars` · `DELETE /api/cmdvars/<id>`. 시험 `tests/test_commands.py`.
  - **함수 인자**(2.18.0): 함수 변수 이름 아래 **인자** 칸에 `이름 · 타입 · 기본값` 을 `＋ 인자 추가` 로 최대 10개(`PARAM_MAX`)까지 정한다. 문구의 `#{이름(값1, 값2)}` 값이 순서대로 그 이름으로 함수 본문에 들어간다(`args[i]` 대신 이름 그대로, `args` 도 계속 됨). 값을 비우거나 덜 넘기면 기본값, 기본값도 없으면 `undefined`.
    - 타입: 문자(그대로) · 숫자(`Number`, 아니면 오류) · 참/거짓(true · false · 예 / 아니오 · 1 / 0) · 날짜(`Date`, `YYYY-MM-DD` · `오늘` · `+3` / `-1` = 오늘부터 며칠). 바꿀 수 없으면 그 자리는 그대로 남기고 이유를 알린다.
    - 서버가 인자 이름 규칙(글자 / _ 로 시작, 30자) · 겹침 · 예약어(`ctx` · `args` · JavaScript 예약어) · 타입별 기본값 형식을 검사한다. 테이블 `cmd_vars.params`(JSON).
    - 목록 · 보기 · 변수 넣기 버튼은 함수를 `#{after(days)}` 처럼 인자와 함께 보여 주고, 넣기는 기본값을 채워 `#{after(1)}` 로 넣는다. 보기에는 인자 표, 편집에는 `문구에서 #{이름(a, b)}` 미리 보기와 실행해 보기의 인수 칸 안내.
  - **기본 내장 함수 추가**(2판): 도움말 예제를 기본 변수로 넣는다 — `#{after(days)}` 며칠 뒤 · `#{now(format)}` 형식을 정한 지금 시각 · `#{next(day)}` 돌아오는 요일(한글) · `#{dday(target)}` 남은 날 · `#{issueTitle}` 지금 일감 번호와 제목 · `#{sign}` 상수 team 과 내 이름. 기본 변수는 판(`settings.cmd_vars_seeded`)마다 한 번만 넣어, 예전 DB 에는 2판만 더하고 지우거나 고친 것은 되살리지 않는다(같은 이름이 있으면 건너뜀).
  - **인수 · 날짜 형식 보완**: 인수 안에 괄호 한 겹(`yyyy-MM-dd(E)`)과 따옴표(`"MM/DD, HH시"`, 안의 쉼표는 나누지 않음)를 쓸 수 있다. 예전에는 `(E)` 의 `)` 에서 끊겨 자리가 통째로 바뀌지 않았고 알림도 없었다 — 이제 형식을 알아보지 못한 `#{…}` 도 이유를 알린다. `ctx.fmt` 형식에 Java 꼴 `yyyy · yy · M · dd · d · H · hh · h · m · s · E(금) · EEEE(금요일) · a(오전/오후)` 를 더했다(예전 `YYYY · DD` 도 그대로, 영문자에 붙은 글자는 바꾸지 않음).

## 2.19.1 — 레드마인 표 · 패치 노트 정리 · 도움말
- **레드마인 표가 표로 보인다**: 본문 · 댓글의 HTML 표(`<table>`)를 칸 태그만 지우던 탓에 `신청번호고객사명…` 처럼 글자가 붙어 나오던 것을 고쳤다. `remoteText` 가 표를 Textile 꼴 `|칸|칸|`(머리칸 `|_. 칸|`) 줄로 바꾸고, `richHtml` 이 이어진 `|…|` 줄(Textile 표 · 마크다운 표 `|---|` 포함, 코드 상자 안은 제외)을 진짜 표(`.rtbl`)로 그린다. 넓으면 표만 옆으로 밀어 보고, 30자 이하 칸은 한 줄로. 서버의 `textutil.plain`(요건 초안)도 칸 사이를 ` | `, 줄 끝을 줄바꿈으로.
- **패치 노트는 최근 10장만**(`PATCH_SHOW`): 새 버전을 처음 열 때 슬라이드는 최근 카드 10장까지만 보여 준다. 카드는 지우지 않는다.
- **설정 → 도움말 탭**: 지금까지의 카드 전부를 주제(`HELP_GROUPS`: 오늘 · 화면 / 레드마인 쓰기 · 댓글 / 코드 · 쿼리 보관함 / 기록 · 메모 · 그래프 / 가져오기 · 알림 / 배포요청 / 앱 · 업데이트 · 백업)별 사용 팁으로 보여 주고, 찾기 칸으로 거른다. 카드의 `g` 가 주제이고, 고친 것만 있는 카드(`g:""`)는 도움말에서 뺀다. 예전 일반 탭의 패치 노트 버튼(최근 변경 · 처음 2.x 안내)도 이 탭으로 옮겼다.

- **고침**: 알림을 한 곳(`rnotes/attention.py` `notify`)으로 모았다. 사용자가 앱 창을 **보고 있지 않으면**(최소화 · 다른 창에 가려짐 · 다른 앱 사용 중 · 창을 닫아 트레이에만 있음) 작업 표시줄 아이콘을 **반짝이고**(`FlashWindowEx` 작업 표시줄 단추 · 창을 맨 앞으로 가져올 때까지) **윈도우 알림**(트레이 말풍선 → 알림 센터)을 띄운다. 보고 있으면 화면 안 알림만.
  - '보고 있다' = 윈도우에서는 앱 창이 **맨 앞(포커스)이고 최소화되지 않았을 때**(`appwin.foreground`). 그 밖(소스 실행 · 시험)에서는 화면이 알려 준 신호 · 숨김 · **포커스**(`document.hasFocus`, 알림 가져오기에 `focus=` 를 더함).
  - 서버가 직접: 메모 알림(`lifecycle.alarm_tick`), 자동 가져오기 새 일감(`autosync._tray_notice`). 화면이 `POST /api/attention` 으로: 오늘 배포 요청(자동 모드에서 모양이 바뀔 때) · 새 버전 알림 · 오늘 볼 메모.
  - **설정 → 일반 → 알림 방식**: 작업 표시줄 아이콘 반짝이기(`notify_flash`) · 윈도우 알림 띄우기(`notify_toast`, 둘 다 기본 켬). 윈도우 알림이 안 보이면 방해 금지(집중 지원)를 확인하라는 안내만 둔다.
  - 시험 `tests/test_attention.py`, `tests/test_autosync.py` 에 '창은 보이지만 다른 앱이 포커스' 경우 추가.

## 2.21.1 — 업데이트 뒤 다시 켜질 때 'python dll' 오류 고침
- **문제**: 앱 안 업데이트로 새 버전을 설치한 뒤 자동으로 다시 켜질 때 `python3xx.dll 을 찾을 수 없습니다` 오류가 났다(그 뒤 직접 실행하면 새 버전이 정상으로 켜짐).
- **원인**: PyInstaller onefile exe 는 실행 중 환경 변수 `_PYI_ARCHIVE_FILE` · `_PYI_APPLICATION_HOME_DIR`(풀어 놓은 임시 폴더 `_MEIxxxx`) 등을 둔다. 업데이트 도우미(cmd) → 설치 파일 → 새 exe 가 이 환경을 그대로 물려받았는데, 새 exe 는 예전 exe 와 **같은 경로**라서 부트로더가 '같은 앱의 자식 프로세스'로 여기고 이미 지워진 예전 임시 폴더에서 python DLL 을 찾았다.
- **고침**: 도우미를 띄울 때 `_PYI_*` · `_MEIPASS*` 를 빼고 `PYINSTALLER_RESET_ENVIRONMENT=1` 을 넘긴다(`updater.clean_env`). exe 만 쓰는 방식 · 바꾸기에 실패해 예전 exe 를 다시 켜는 경우도 같다. 시험 `tests/test_update.py` 에 추가.
- 참고: 고친 코드는 **업데이트를 시작하는 쪽(지금 켜진 앱)** 에서 돈다 — 2.21.0 이하에서 2.21.1 로 올라올 때는 한 번 더 뜰 수 있고, 2.21.1 부터 다음 업데이트는 괜찮다.

## 2.22.0 — 노트 탭 · 새 댓글로 바로 이동 · 오른쪽 아래 알림 창 · 진행 기록 줄바꿈 고침 (#28)

- **오른쪽 아래 알림 창** (`rnotes/popup.py`, 윈도우): 창을 보고 있지 않을 때(닫힘 · 최소화 · 가려짐) 자동 가져오기에서 새 일감 · 남이 단 새 댓글/변경(가져오기 전 수정 시각 뒤, 내 것 · 배포요청 제외)이 있으면 카카오톡 알림처럼 작업 표시줄 위에 작은 창을 띄운다. 포커스를 빼앗지 않고 8초 뒤 사라지며(마우스를 올리면 기다림) 여러 건은 위로 쌓이고, 4건 이상이면 2건 + '새 소식 N건 더'. 누르면 앱 창을 앞으로 가져와(닫혀 있으면 `?open=번호` 로 새 창) 그 노트의 새 댓글로 이동한다 (`/api/open-req`). 설정 → 알림 방식에서 끄거나(`notify_popup`, 끄면 윈도우 알림으로) 미리 볼 수 있다 (`/api/popup/test`). 자동 가져오기의 '새 일감 알림'은 '새 일감 · 새 댓글 알림'이 됐다.

## 2.22.1 — 탭 줄 · 새 댓글 묶음 다듬기, 알림 창 윈도우 시험
- **탭 줄**: 노트와 색이 비슷해 구분이 안 되던 것 — 탭 줄 바탕을 진하게, 지금 탭은 흰색(다크 테마는 밝은 회색) + 위쪽 강조선. 탭이 하나뿐이면 탭 줄을 숨긴다 (탭은 그대로 기억).
- **새 댓글로 바로 이동**: 댓글 · 변경을 하나씩 칠하던 것을, 첫 새 소식부터 마지막까지 `NEW · 새 댓글 · 변경 N건` 영역 하나로 묶어 보여 주고 그 영역으로 이동한다.
- **트레이 상태에서 알림이 안 뜨던 것**: 알림 창은 자동 가져오기가 찾은 변동에만 뜨는데, 자동 가져오기 기본값이 꺼짐(0분)이라 창을 닫으면 레드마인을 확인하지 않았다. 설정 → 알림 방식에 지금 상태(몇 분마다 확인하는지 / 꺼져 있으면 경고)와 '10분마다 자동 가져오기 켜기' 버튼을 둔다.
- **오른쪽 아래 알림 창**: 빌드(windows-latest)에서 실제 창을 띄워 위치(작업 표시줄 위 오른쪽) · 나타나기 · 누르기 · × · 저절로 닫힘 · 최대 개수를 확인하고 화면을 찍어 둔다 (`tests/test_popup.py`, Artifacts 의 `popup-shot-<버전>`).

## 2.22.2 — 화면도 탭으로
- **화면 탭**: 노트만 탭이 되던 것을, 메모 · 트러블슈팅 · 요약 · 그래프 · 내 기록 · 배포요청 · 코드 이력 · 보관함(코드 · 쿼리 · 명령어) 화면도 탭으로 연다 (`TAB_SCREENS`). 화면은 하나씩만 열리고 메뉴에서 다시 누르면 그 탭으로 간다. 오늘 · 이력은 노트 목록이라 탭이 아니다.
- 노트 탭에서 노트를 열면 지금처럼 그 자리를 바꾸고, 화면 탭에서 연 노트는 화면 탭을 두고 오른쪽에 새 탭으로. 탭마다 보던 위치 기억 · 다시 켜면 복원 · `Alt+PageUp/PageDown` · `Alt+W` 가 화면 탭에서도 된다.

## 2.22.3 — 앱 안 업데이트 '[WinError 5] 액세스가 거부되었습니다'
- **바꾸기 단계가 막히던 것**: 도우미 파일을 늘 같은 이름(`apply-update.cmd`)으로 덮어써서, 지난 도우미나 백신이 붙잡고 있으면 `WinError 5` 로 멈췄다. 이제 매번 새 이름으로 쓰고(`write_helper`) 지난 것은 지울 수 있으면 지운다.
- 도우미 파일을 못 쓰거나 `cmd.exe` 를 못 띄우면(보안 정책 · 백신), 설치 파일 방식은 받아 둔 설치 파일을 바로 실행한다 (`/VERYSILENT … /CLOSEAPPLICATIONS /RELAUNCH=1` — 설치 파일이 켜진 앱을 닫고 설치한 뒤 다시 켠다).
- 그래도 막히면 어느 단계(확인 · 받기 · 바꾸기)에서 무엇 때문에 막혔는지, 받아 둔 파일 위치와 함께 알려 준다.
- **Ctrl+W 로 창 전체가 닫히던 것**: 앱 창(--app)에서는 브라우저가 단축키를 화면에 먼저 넘기므로 `Ctrl+W`(`Ctrl+F4`)를 막고 지금 탭을 닫는다. 탭이 없으면 창을 닫지 않고 안내만. 크롬처럼 `Ctrl+Tab` · `Ctrl+Shift+Tab` · `Ctrl+PageUp/PageDown` 으로 탭 이동, `Ctrl+1~8` 그 번째 · `Ctrl+9` 마지막 탭.

## 2.22.4 — 메뉴 화면도 크롬처럼 (새 탭은 휠 클릭 · Ctrl+클릭)
- 메뉴(메모 · 트러블슈팅 · 요약 …)를 그냥 누르면 늘 새 탭이 생기던 것을, 노트와 같이 **지금 탭을 그 화면으로 바꾸게** 했다. 이미 탭으로 열려 있는 화면은 그 탭으로 간다.
- 메뉴 항목을 **휠 클릭 · Ctrl+클릭** = 새 탭(지금 화면은 그대로), **Ctrl+Shift+클릭** = 새 탭으로 이동 (전에는 메뉴에서 안 됐다).
- 노트 탭이 화면으로 바뀌면 그 노트는 닫힌 것으로 (이력 · 오늘에서 저절로 되살아나지 않게). 보고 있는 탭이 없을 때(이력 목록만 보는 중) 노트를 열면 다른 탭을 바꾸지 않고 옆에 연다.

## 2.22.5 — 목록 줄 정리 · 목록에서 바로 번호 · 제목 복사
- 목록 줄에 마우스를 올리면 오른쪽에 **번호 복사(`#12345`) · 제목 복사** 단추가 나온다. 노트를 열고 맨 위까지 올라가지 않아도 된다.
- 목록에서 **상태 점 · `대기 · N일 전 수정`(수정일) · 비슷한 과거 N건**을 뺐다. 노트 본문에는 그대로 있다.
- ☆ 고정 단추를 줄 왼쪽 끝에서 **오른쪽 끝**으로 옮겼다.
- 줄 안 단추(복사 · ☆)에서 Enter 를 누르면 노트가 같이 열리던 것을 막았다.

## 2.22.6 — 목록 제목을 넓게 · ↑ 맨 위로 단추 겹침
- 목록 줄의 번호 · 제목 복사와 ☆ 고정 단추를 제목 오른쪽에서 **아랫줄(번호 · 구분 줄) 오른쪽**으로 내렸다. 제목이 줄 전체 너비를 써서 한 줄에 더 많이 보인다. 지켜보는 중의 숨기기 단추도 같은 자리.
- **↑ 맨 위로 단추가 💬 댓글 단추와 겹치던 것**: 스크롤로 아래 댓글 쓰기 칸이 보였다 사라질 때 💬 단추만 숨기고 보이면서 단추 줄 자리를 다시 정하지 않아, 그사이 💬 자리로 간 ↑ 와 겹쳤다. 💬 가 숨거나 나타날 때마다 ↑ · ☑ 자리를 다시 정한다.

## 2.22.7 — 공휴일 받아 오기(공휴일 API) 삭제
- 자동 가져오기가 매주 첫 영업일에 공공데이터포털 `한국천문연구원_특일 정보`에서 그 주 공휴일을 받아 오던 기능을 **완전히 뺐다**(`rnotes/holiday_api.py` · 내장 인증키 · `POST /api/holiday/fetch` · 설정의 `이번 주 다시 받기` 단추 삭제).
